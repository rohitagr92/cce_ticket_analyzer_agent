# PossibleRootCause — End User Conferencing Rooms

## CRITICAL INSTRUCTIONS – READ FIRST

Use this file to choose one technical/system-level root-cause label for Rooms incidents. Do not turn the label into a sentence. Narrative belongs in AI Analysis.

## PURPOSE
Provide short, bold root-cause labels that the AI can reuse consistently.

## RULES
- Use only the labels listed here.
- Keep the output short and specific.
- Prefer a concrete root cause over a vague label.

## ROOT CAUSE LABELS
- **Audio Driver Failure**
- **Device Enumeration Failure**
- **Audio Processing Pipeline Failure**
- **Hardware Component Failure**
- **Peripheral Compatibility Issue**
- **Teams Media Stack Failure**
- **Meeting Room Integration Failure**
- **Camera & Video Pipeline Failure**
- **Network Media Quality Issue**
- **Device Firmware Issue**
- **Resource Exhaustion**
- **Power / Connectivity Failure**
- **Unknown / Unclear**

## ROOT CAUSE GUIDANCE
- Use **Audio Driver Failure** for driver corruption, incompatibility, or initialization failure.
- Use **Device Enumeration Failure** for detection, discovery, or USB enumeration failures.
- Use **Audio Processing Pipeline Failure** for media engine, codec, or rendering path failures.
- Use **Hardware Component Failure** for failing microphones, speakers, cameras, or room devices.
- Use **Peripheral Compatibility Issue** for headset, Bluetooth, dock, or accessory incompatibility.
- Use **Teams Media Stack Failure** for media session, voice engine, or transport failures.
- Use **Meeting Room Integration Failure** for room device synchronization or console communication failures.
- Use **Camera & Video Pipeline Failure** for camera driver, initialization, capture, or rendering failures.
- Use **Network Media Quality Issue** for packet loss, jitter, latency, or bandwidth issues.
- Use **Device Firmware Issue** for firmware incompatibility, corruption, or unsupported versions.
- Use **Resource Exhaustion** for CPU, memory, GPU, or disk contention.
- Use **Power / Connectivity Failure** for unplugged, offline, or cabling-related room outages.

## CRITICAL OUTPUT RULES

- Output only one root cause label.
- Do not include explanations or extra punctuation.
- Keep the label exactly as shown in the list above.
